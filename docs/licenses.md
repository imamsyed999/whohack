# License policy

whohack is licensed under **MIT OR Apache-2.0**; see `LICENSE-MIT` and `LICENSE-APACHE`.

## Rust dependencies

These are enforced in CI by `cargo deny`, configured in `deny.toml`. Allowed licenses:

- MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, Zlib, Unicode-3.0;
- Apache-2.0 WITH LLVM-exception (wasmtime/cranelift via yara-x). This is Apache-2.0 plus an
  extra permission.

Any other license needs maintainer approval and an entry here.

Both Cargo workspaces pass the 2026-10-15 audit with documented exceptions.
The maintainer's delegation approved five exact-version MPL-2.0 exceptions;
see the [license review](license-review-2026-10-14.md). The GTK macro advisory and
unreachable Wasmtime features are recorded in the
[advisory review](advisory-review-2026-10-15.md). Exceptions are risk acceptance,
not upstream fixes or production-release clearance.

Windows binary packages include `THIRD-PARTY-NOTICES.txt` and its exact-version
source inventory, generated by `tools/windows/notices.py`. These cover registry
dependencies from both Windows dependency graphs, including build dependencies.
Linux packages have their own target-specific inventory. Python/model
environments are separate and are not bundled in the preview.

YAML rules and category templates use
[`serde-saphyr`](https://docs.rs/serde-saphyr/1.3.0/serde_saphyr/) under MIT OR
Apache-2.0, with only its local deserialization feature enabled. It passes the
repository's license/advisory checks; no network client was added for this work.

## Python decision-model sidecar

The sidecar runs the typed-decision model (see `docs/research/decision-models.md`). It ships as
a separate process with its own Python environment. Approved exceptions:

| Package | License | Why it is present | Approved |
|---|---|---|---|
| `certifi` | MPL-2.0 | CA bundle pulled in by `requests` / Hugging Face libraries | 2026-10-03 (maintainer) |
| `tqdm` | MPL-2.0 AND MIT | progress bars used by Hugging Face libraries | 2026-10-03 (maintainer) |

MPL-2.0 is file-level copyleft. whohack uses these packages unmodified and does not include
their source in its own files, so whohack's own license is unaffected.

Packaging notes:

- **Use the CPU-only PyTorch wheel.** CUDA wheels bundle NVIDIA's redistributable libraries,
  which come under NVIDIA's own license terms.
- **Model weights are Apache-2.0.** This covers `manjunathshiva/opendecider-nano` and
  `convaiinnovations/laya`.
- **Training data provenance:** upstream reports include CC BY-SA material.
  The published model cards declare Apache-2.0 for the weights. Review the
  applicable dataset terms separately before redistributing training data;
  the weights' license is not permission to relicense their source datasets.
